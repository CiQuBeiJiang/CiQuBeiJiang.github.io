## 关于本站

这是一个基于 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 构建的静态网站，部署在 GitHub Pages 上。

记录内容包括：
- **数据分析** - Pandas、Matplotlib、Seaborn 学习笔记
- **机器学习** - 算法理解与代码实现
- **运筹优化** - 线性规划、整数规划探索
- **技术札记** - Git、Markdown、LaTeX 等工具使用
- **文学与哲学** - 阅读笔记与思考

## 访问地址

🔗 https://ciqubeijiang.github.io

## 本地开发

```bash
# 安装依赖
pip install -r requirements.txt

# 本地预览
mkdocs serve

# 构建站点
mkdocs build
```

## 部署

站点通过 GitHub Actions 自动部署，推送至 main 分支后自动更新。
