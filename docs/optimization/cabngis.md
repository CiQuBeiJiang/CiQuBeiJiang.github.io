# CABNGIS：预算受限下的光储充协同调度搜索

!!! abstract "项目摘要"

    **CABNGIS**（Constraint-Aware Budgeted Neighborhood-Guided Iterative Search，约束感知预算化邻域引导迭代搜索）研究光伏、储能与电动车充电家庭微网中的调度搜索问题。候选调度方案的生成代价很低，而每次**精确评估**（求解一次储能 QP）都会消耗预算，因此核心问题是在固定预算下确定候选的精确评估顺序。

    方法以约束感知排序替代单纯按目标值排序：优先依据候选是否导致储能越界、与约束边界的距离以及到可行域的投影距离排序，其次比较目标值。

    **主要结论**：约束感知排序使接近参考值的解**更早出现**（91 天 × 10 个种子的主实验中，71 天更快，Wilcoxon $p<10^{-10}$），但**不能稳定减少总评估次数或运行时间**。早期报告的"比 SG-LNS 少 49% 评估次数"在统一停止规则后不再成立，已撤回。

## 1. 问题定义

### 1.1 系统与决策变量

一天划分为 $T=12$ 个时段（每段 2 小时）。一个候选方案写作 $z=(s,\delta)$：

- $s_t\in\{1,2,3\}$：各时段的 **谷 / 平 / 峰** 标签；
- $\delta\in\mathbb{R}^3$：分别控制 峰→谷、峰→平、平→谷 三个方向转移多少负荷，经过线性映射与截断变成转移比例 $\alpha\in[0,0.3]$。

$(s,\delta)$ 共同决定一条充电引导曲线 $p_{\text{guide}}$：负荷在不同类别时段之间转移，再投影回单纯形以保持总需求不变。

![图 1　光储充系统结构：光伏出力、储能 SOC 约束、原始充电需求与分时电价共同决定调度](/optimization/images/cabngis/fig01-system.png)

### 1.2 下层：储能精确子问题

给定 $p_{\text{guide}}$，储能充放电计划由一个 QP 精确求解（Gurobi）：

- 储能功率 $P_{\text{net}}\in[-2000,2000]$ W，SOC $\in[0,5000]$ Wh，满足 SOC 递推；
- 购电 $P_{\text{buy}}\ge$ 净负荷，峰值 $P_{\text{peak}}$ 约束所有时段的购电。

目标函数是三项归一化指标之和（各项均以无控制基准值归一化，数值越小越好）：

$$
q = \frac{\overline{P_{\text{net-load}}^2}}{f_1^{\text{base}}}
  + \frac{\sum_t c_t P_{\text{buy},t}\Delta t}{f_2^{\text{base}}}
  + \frac{P_{\text{peak}}}{f_3^{\text{base}}}
$$

分别对应 **净负荷波动、分时电价成本、峰值购电**。分时电价 $c_t$ 在 0.30 到 0.80 之间。

!!! note "研究问题"

    候选生成的代价可以忽略，主要开销来自精确评估。因此研究重点在于**固定预算 $B$ 下候选送入精确评估的顺序**。

## 2. 算法流程

主循环在 `neural_lns_consolidated.run_neural_lns` 中，分为五个步骤：

![图 2　CABNGIS 主循环：由精英档案生成候选邻域，按优先级选出前若干个候选送入精确评估，再更新档案](/optimization/images/cabngis/fig02-loop.png)

1. **初始化**：用一批结构化模板（全峰、全平、全谷、光伏匹配、电价最优等，加上扰动和随机解）与 14 点 $\delta$ 网格组合，经低成本打分后选取多样化子集进行精确评估，建立精英档案。
2. **邻域生成**：每轮生成 48 个候选，60% 来自变异（破坏 2–5 个时段的标签，$\delta$ 加高斯噪声），20% 来自路径重连，20% 从种子池重启。
3. **约束感知排序**：详见第 3 节。
4. **精确评估**：排名靠前的候选送入 Gurobi 求解。结果按候选缓存，命中缓存不计预算。
5. **停止**：用尽 $B=80$ 次不重复的精确评估、达到迭代上限或长时间无改进时停止。

路径重连对两个精英解的标签逐位随机继承，$\delta$ 取凸组合：

```python
child_s = np.where(rng.rand(len(s_a)) < 0.5, s_a, s_b)
child_d = alpha * d_a + (1 - alpha) * d_b
```

## 3. 约束感知排序

对每个候选，先根据 $p_{\text{guide}}$ 和光伏出力计算储能需承担的功率 $\text{req}=-(p_{\text{guide}}-p_{\text{pv}})$，并计算以下指标：

| 指标 | 含义 |
| --- | --- |
| 违约量 | SOC 过低 / 过高、功率超限的程度 |
| 边界风险 | 落入距 SOC 容量 12%、功率上限 10% 范围内边界带的深度 |
| 投影距离 | 需求功率到储能可行集的 L1 投影距离 |
| 代理目标 | 不求解 QP、由引导曲线直接估算的目标值 |
| 新颖度 | 与档案中已有解的差异 |

默认按 **(违约等级, 边界风险, 代理目标)** 做字典序排序；也提供加权版本 $\text{score}=\text{obj}+8.0\cdot\text{violation}+2.5\cdot\text{risk}$。消融实验里的 "objective-only" 即去掉违约与边界风险两项，仅按目标值排序。

!!! tip "名称说明"

    早期版本名为 Neural-Guided，源于一个可选的 MLP 预打分器（256→128→64，预测 $\hat q$）。最终实验结果支持的是**解析的约束排序**而非神经网络，因此更名为 Neighborhood-Guided。

## 4. O(T) 储能投影

投影距离原本需要求解一个含 $2T$ 个变量的 LP（HiGHS）。对于无权重且没有终端 SOC 等式约束的情形，可按时间顺序逐段截断求解，等价于离散的双边 Skorokhod 反射：

```python
for idx in range(T):
    lower = max(-P_max, -soc / dt)          # SOC 下界
    upper = min(P_max, (CAP - soc) / dt)    # SOC 上界
    projected[idx] = np.clip(projected[idx], lower, upper)
    soc += projected[idx] * dt
```

该方法在上述条件下是 L1 最优的，时间复杂度 $O(T)$，额外空间 $O(1)$。验证结果如下：

- 619 次请求与 LP 结果一致到 $10^{-7}$；
- 240 次完整搜索替换前后，目标值和评估次数完全不变；
- 另有 4 个回归测试。

![图 3　(a) 示例中因果反射与 LP 的投影不同但 L1 距离相同（6.489 kW）；(b) 中位耗时随时域长度增长，反射的对数斜率为 0.99，LP 为 1.47](/optimization/images/cabngis/fig03-projection.png)

## 5. 数据

- **Ausgrid Solar home electricity data 2011–2012**，Customer 12（1.04 kWp，CC-BY 3.0 AU）。半小时数据聚合成 12 个时段。
- 数据集中没有电动车充电记录，以家庭用电作为充电需求的替代。
- 测试集是 2012 年 4 月 1 日到 6 月 30 日的 **91 个留出日**。
- 此外还包括 Boulder 外部站点（30 个站点日、3600 次运行）和高负荷压力场景（需求 +25%）。

## 6. 实验结果

### 6.1 主实验

设计：91 天 × 10 个种子 × 7 种方法 = **6,370 次运行**，预算 $B=80$，共记录 475,844 行逐次评估轨迹。

指标 $N(\theta)$：首次满足 $\text{best}_q\le(1+\theta)\,q_{\text{ref}}$ 时所用的精确评估次数，未达到记为 81。

CABNGIS 对比 objective-only（$\theta=0.1\%$）：

| 项目 | 结果 |
| --- | --- |
| 逐日比较 | 71 天更快 / 11 天持平 / 9 天更慢 |
| 均值差 | −11.26 次，95% bootstrap CI [−15.75, −7.08] |
| 中位数差 | −2 次，CI [−3, −1] |
| 显著性 | Wilcoxon $p<10^{-10}$，符号检验 $p=4.4\times10^{-13}$ |
| 未达标 | 1/910 对 63/910 |

![图 4　优先级消融（12 个测试日，阈值 1%）：各变体多数在第 8 次评估内达标，差异仅出现在少数离群日，仅作机制层面参考](/optimization/images/cabngis/fig10-ablation.png)

23 个次要检验经 Holm 校正后 18 个显著；与 SG-LNS 相比，在不同阈值下未表现出稳定差异。

### 6.2 公平停止审计

早期实验显示 CABNGIS 比 SG-LNS 少用 49% 的精确评估。复查发现该差距来自实验协议不一致：批大小不同、按迭代数计的耐心值、改进阈值不同（SG-LNS 用 0，CABNGIS 用 $10^{-5}$）。

- 仅统一批大小时，CABNGIS 仍领先约 32%；
- 进一步统一 `min_improvement = 1e-5` 后，差距反转：39.88 对 39.33 次，差 +0.55，CI [−0.29, 1.67]。

预先登记的检验门槛未通过，该结论已撤回。解的质量差异为 +0.001%，满足非劣性。

### 6.3 其他对比

- **对比 GA / PSO / NSGA-II**（统一停止规则）：解质量非劣，评估次数节省 1.8%–4.6%，但置信区间均包含 0，节省不显著。
- **高负荷场景**：精确求解代价较低时，排序开销占主导。Traditional-LNS 用时 0.146 s，CABNGIS 用时 2.68 s（约 18 倍），且未达到 0.1% 目标。
- **Boulder 外部研究**：一个 router 变体在 $B=20$–80 下质量提升约 10%（CI 不含 0），但评估次数未减少，运行时间增加 180%–280%，仅作为固定预算下的机制性证据。

![图 5　Boulder 评分分解：储能项差距不超过 0.013，得分优势主要来自会话惩罚项（差 0.031–0.056）](/optimization/images/cabngis/fig09-boulder.png)

## 7. 总结

实验结果表明，约束感知优先级（投影距离 + 边界风险）改善了候选的评估顺序，使接近参考值的解更早出现；但在统一停止规则后，该方法没有稳定减少总评估次数或运行时间。

本项目的主要贡献包括：预算化的邻域搜索框架、$O(T)$ 精确储能投影，以及一套经过公平性审计的实验协议。审计中，早期"减少 49% 评估次数"的结论在对齐批大小、停止规则与改进阈值后不再成立，最终结论只保留经过验证的部分。
