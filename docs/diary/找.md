# 找
书桌一团糟，胶卷又找不见了。

不在桌上的收纳盒里，也不在放相机的架子上。

我不知道上次整理书桌的时候，又自作聪明的把它们塞到哪里去了。

我的记忆很差，或者说很奇怪。

我很多时候不会记得东西随手放到哪去了，今天发生了什么，朋友的名字，甚至他们的长相。

但我会记得一些奇怪的东西：某人几年前随口一提的一句话，桌角掉落的一个回形针。

我不知道我为什么会记住，但它们就是这样的，确实发生了。

也许我的大脑有特殊的遗忘程序，会自动清理不特别的东西。

比如——日复一日机械般的生活。

有个朋友说我很“傲慢”，因为我会做自己的表情包，会起自己的网名，总想和别人不一样。

是这样的，我经常会不知道我到底是谁。

有时候感觉世界很小。

我能从一张又一张陌生的脸上，看见一个又一个熟悉的人。

食堂里低头吃饭的人，便利店正在付款的人，雨天站在屋檐下面等车的人。好像只要把五官稍微打乱重组一下，人类就会重新长出同样的神情。

世界每天都会制造很多人。

制造他们的眼睛，习惯，口音，孤独，还有那些说不出口的话。

我到底是谁？

我也只是某些人的碎片，重新拼起来的东西吗？

或者只是某个游戏里，一个站在固定位置的npc？

我不知道。

也许我也会被谁羡慕？

也许也有人觉得，不能失去我？

我也不知道。

但第二天醒来的时候，地铁还是一样拥挤。

便利店还是有人低头付款。

雨天还是有人站在屋檐下面等车。

世界好像一个反复使用的模具，人只是不同批次的产品。

我需要一个名字。

就像需要一个批次号。

不然很容易和别人放混，连自己都找不到。
