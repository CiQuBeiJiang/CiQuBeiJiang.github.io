# 伞
很想有一把好用的伞。只是不用来挡雨。

我买过很多伞，但撑开以后，总是再卷不回原来的样子，久而久之，这个伞就变得皱巴巴的，像一张爬满皱纹的脸。

现在用的伞是一把长柄伞。我觉得它很帅，好像一把长剑，又好像一根公爵用的拐杖。后来觉得其实也不好用——我不知道应该怎么拿？竖着胳膊会很累，横着看起来很蠢。但我也懒得买新的，就一直用着。

平时我也不会把它重新绑起来，就放在宿舍洗手间的墙边。不知道为什么，天花板总是落下一些白色的粉尘，盖在伞上。太久不用，拿起来一手灰尘，撑开更是能狠狠地呛我一口。我也懒得换位置。

这把伞足够大，大到够两个人一起打，但我从来没有同另一个人一起过。不过它还是为我撑起了一个很大的空间。

在雨天，撑开的伞，像一块临时划分的领地，没人会擅自闯入。再带上耳机，隔绝一切声音。世界安静了，大世界里有了一小块独属于我的世界，即使是片刻。

有人曾经跟我说，淋雨对身体不好，因为雨滴会夹带灰尘，通过毛孔进攻你的身体。我不知道是真的吗？

有可能，我其实喜欢淋雨，因为一个湿透的人会看起来很忧郁，就好像小说里等女主的男主一样。

我的头发有些自然卷，交错纵横。雨打在头发上，会震颤一下，仿佛打到了一片叶子上一般。

小一点的雨滴就附着在末梢了，大一点的雨滴可以借助重力从缝隙中钻进去，有点凉，有点痒。最后从脸上滑落，感觉像出汗，又感觉像哭泣——某个人用我的脸哭了出来。

也可能，只是懒得打伞。

一个人占据两个人的空间。

南京又在下雨。
