> 只有用心才能看清。本质的东西，眼睛是看不见的。


总想写点什么，但不知道写点什么。

很多事情我都会忘记。
吃过的东西，说过的话，甚至一些本该重要的时刻。
回头看的时候，它们不见了，只剩下一点模糊的影子。

所以我写。

也不一定写下了什么。
有时候只是一个念头，有时候是一点来不及分辨的悲伤。

写了只是写了。
但不写，它们大概就真的消失了。

那就先放在这里。
