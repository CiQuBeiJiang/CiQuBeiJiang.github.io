# 时差
时差是一个很奇怪的词。

在没有离开一个地方之前，他只是地理课本上的一个东西，伦敦和中国的时间相差七个小时，冬天是八个小时，很好算，甚至不需要计算器。

假如我一小时跨越一个时区，从本初子午线开始，一路向西，时间对我来说就是静止的——在回到这里之前。

我这里起床的时候，你那里已经吃过午饭了；傍晚走出宿舍，想和你分享今天的晚霞，但估摸着你已经睡了。等到大概你起床的时候，似乎我也懒得说了。

地球上所有的人共用一个世界时间，但彼此之间好像有独特的时差。

大抵就是我想起你的时候，你在睡觉；你想起我的时候，我在上课；我们彼此想起对方的时候，也不知道应该说些什么。

“你那里几点了”，我很想问你，但是没有，我怕你会觉得我很笨。

其实我当然知道你那里几点了，手机上有时间，别人也能告诉我，现在是北京时间几点钟。

可我还是想问你。

我是想知道，在我看不见的那七个小时里，你正在过怎样的生活。

我也想知道，在我看不见的那七个小时里，你有没有想起过我。
