# 风
大部分时间，天空总是灰蒙蒙的，云层低低的压在路灯上，风从街道的一头跑到街道的另一头，偶尔捎来一阵细雨。

很少有人打伞。他们说，这是因为风太大了，伞会被它夺走。

我也没有打伞。

一阵强风刮来，没有带走什么。

只是让我想起了另一场风。

冬天北冰洋的岸边，风裹挟着雪，发出刺耳的咆哮声，砸在脸上，像一粒粒碎石。

雪没过膝盖，每走一步，都要费力地把腿拔出来。身后留下的脚印，还没来得及回头看，就被风雪抹平了。

海面并没有惊涛骇浪，只是一阵又一阵的波澜。不远处有一条船，也许是科考船？或只是游船。

我当时想要什么？

我的愿望——要带着相机，和我的爱人，搭乘邮轮，去地球的北边追极光。

怎么说呢，实现了一半——确实有相机，也看到了极光。

但那天的极光并不明显，不像社交媒体上那样光彩动人，只是淡淡的白光，好像一片发光的雾。肉眼根本看不出什么，只有相机长曝光，才能看到绿色的光晕。

零下二十度，为了操作相机，我把手从手套里拿出来。

调好参数，按下快门。十几秒过后，屏幕上出现了绿色的天空。

我抬头看了看，又低头看了看相机。

明明是同一片天空，看起来却如此不同。

又拍了几张照片，试着调整曝光时间，想让它看起来更接近我曾经想象中的样子。

可不管怎么调整，眼前的天空始终是灰白色的。

突然想起，我曾经想象过无数次这样的场景。

我会和爱人一同站在地球的北边。我们也许会牵着手，也许会拥抱，也许什么都不做，只是安静地望着天空。

但我从来没有认真想过，那个人究竟是谁。

大家都在拍极光，没有人开灯，除了天空，一切的一切都揉成了一团。

我好想给我们拍一张，但是她不存在。

她应该是什么样的？

漂亮的？温柔的？善解人意的？

如果她并不漂亮，并不温柔，甚至并不理解我，我还会想和她一起站在这里吗？

我不知道，只是突然发现，我似乎一直在期待一个关于爱情的场景，却从未真正想清楚，自己期待的究竟是爱情，还是那个场景本身。

相机还在继续曝光。

我站在旁边，等着它把那些肉眼看不见的光记录下来。

真奇怪，明明冷得要命，手指却像被烫着了一样。没过多久，就麻木了。

回到车上，才发现手变得一片通红，慢慢有了针扎的感觉。

十几秒钟，足够让一片灰白色的天空变得绚烂。

可十几秒钟之后呢？

长曝光可以把十几秒拉成一片绚烂，可永远不是长曝光，永远是一秒一秒熬过去的灰白。

我永远爱你。

说出这句话的人，是不是也在惩罚自己。

离开前，我摇下车窗，最后看了一眼天空，还是灰白色。

又是一阵风吹来，我浑身一哆嗦，裹紧了冲锋衣。

不知道是为了留住体温，还是为了留住灵魂。
