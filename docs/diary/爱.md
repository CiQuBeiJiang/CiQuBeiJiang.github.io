# 爱
有时候回老家，会被我的奶奶催婚，说我都二十多了，怎么还不找个女朋友。

在他们的观点里，恋爱就是一件很简单的事情，两个人认识，聊聊天，觉得彼此还不错，然后就在一起，再然后就结婚了。

但我好像在这件事情上畏手畏脚。

不知道是我把爱想的太复杂，还是他们把爱想的太简单。

他们说，“爱”以前写作“愛”，自从一九五六年开始，人们谈论起爱便少了颗真心。

这大概怪不到简体字头上。

现在的人谈论爱，总有很多东西可以谈。长相、性格、学历、工作、家庭，还有一些我叫不上名字的条件。喜欢一个人以前，最好先想想合不合适；决定在一起以前，还要想想以后怎么办。

这些当然都没有错。

我自己也是这样的人。

只是算得多了以后，我偶尔会想，那个什么都还没来得及算，就已经喜欢上一个人的“心”，到底去了哪里。

是环境让我们不得不计算，还是人长大本能就会权衡？

说来有些矛盾，我明明也是一个做什么都喜欢想很多的人，却一直很向往故事里的爱情。

就像小说或者动漫里写的那样。男女主一见钟情，然后坠入爱河，经历过各种各样的事件，最后相伴终生。

我知道这些都是假的。

故事一般写到公主和王子举行了婚礼，最后幸福的生活在一起就结束了。至于第二天早上谁先起床做早饭，晚上睡觉有没有人打呼噜之类的，并不在作者的考虑里。

现实里的爱似乎麻烦很多。

当你发现对一个人有好感的时候，你会纠结这到底是喜欢还是爱，是欲望驱使还是发自内心。

两个人初见彼此都有好感，最后也可能只是加上微信，寒暄几句，就到此为止了。

即使确定了情侣关系，也可能在一次次争吵中破碎，让两个本来就难以亲近的人离得更远。

至于相伴终生，那就更难了。

中国人均预期寿命是八十岁，假设从二十岁开始，所谓相伴终生是六十年，也就是两万一千九百一十五天。

在小说里，只用一个“永远”就写完了。人的一生就这样被压缩到这两个字里。

我其实不知道我为什么渴望这样的爱。

明明知道一见钟情多半只是长相恰好符合喜好，知道荷尔蒙会消退，知道两个人在一起久了总会争吵，知道世界上没有谁是为了谁而出生的。

道理我都知道，但是没有用。

就好像我知道熬夜不好，但我还是熬夜。

也许我想要的爱，大概并不真是小说里的爱。

我似乎并不需要某人在下雨天冲过来给我送伞，也不需要在烟花升起的时候相拥，更不需要无数个机缘巧合证明我们是天生一对。

我只是很羡慕他们。

他们是确定的——喜欢就是喜欢，想念就是想念。分别以后会去寻找，误会以后总有机会解释。哪怕故事绕了很远，读者也知道他们最后会重新遇见。

有时候看完一部动漫，已经是凌晨两三点了，随着电脑关机，房间里最后一点光也从窗帘的缝隙里渗出去，融进夜色。

我会闭上眼睛，偷偷变成故事里的主角。

现实不一样，没有人知道哪一次分别只是剧情的转折，哪一次分别就是结局。

也没有人提醒我，今天见到的这个人，会不会在很多年以后依然坐在我的旁边。

下次回家的时候，奶奶大概还是会问我，有女朋友了没有。

我大概还是不知道怎么回答。

总不能向她解释现代人的算计与犹豫，或者我对一段关系随时可能无疾而终的恐惧。

也许只是因为，我还在期待这么一个人。

“愛”里的心消失了，我的还在。
