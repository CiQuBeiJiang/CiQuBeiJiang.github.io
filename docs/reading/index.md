# 阅读

留在书页、页边与深夜笔记里的安静痕迹。

这里收纳的是档案中更缓慢的一部分：

- 文学
- 哲学
- 阅读笔记
- 页边批注

它们不那么强调结论，更像阅读结束后留下来的残余：划线、摘要、和一些没有立刻散去的想法。
