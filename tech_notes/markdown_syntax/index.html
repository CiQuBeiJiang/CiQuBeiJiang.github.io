Markdown 核心语法与数学公式速查手册¶

简介：Markdown 是一种轻量级标记语言，目标是「用简单的语法实现结构化文本排版」。无需鼠标点击，只需添加少量特殊符号，即可生成标题、列表、公式等。

1. 基础排版¶

标题¶

使用 # 数量表示层级，# 后必须加空格。

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

换行与段落¶

  • 换段：两段文字之间直接空一行

  • 换行：在行末输入两个空格后回车（或直接空一行换段，更通用）

文本样式¶

效果 语法 示例
加粗 **内容** 加粗内容
斜体 *内容* 或 _内容_ 斜体内容 / 斜体内容
删除线 ~~内容~~ ~~删除线内容~~
粗斜体 ***内容*** 粗斜体内容

分割线¶

三个或以上的 - 或 *，需单独成行：

---
***

2. 列表与结构¶

无序列表¶

使用 -、+ 或 * 加空格，支持嵌套（缩进 2-4 个空格）：

- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2
    - 子子项目 2.2.1

有序列表¶

使用 数字. 加空格，自动编号：

1. 第一项
2. 第二项
3. 第三项
   1. 子项 3.1
   2. 子项 3.2

勾选框 (Task List)¶

- [ ] 待办任务 1
- [ ] 待办任务 2
- [x] 已完成任务 1
- [x] 已完成任务 2

引用¶

使用 > 符号，支持嵌套：

> 这是一级引用内容
> > 这是二级嵌套引用
> > > 这是三级嵌套引用

3. 代码与链接¶

代码块¶

使用三个反引号 ``` 包裹，可指定编程语言（如 java、python）：

public class Main {
    public static void main(String args[]){
        System.out.println("Hello, World");
    }
}

行内代码¶

使用单个反引号 ` 包裹：

示例：在 Java 中使用 System.out.println() 输出日志。

链接与图片¶

类型 语法格式 示例
链接 [链接文字](URL地址) 百度
图片 `

4. 表格¶

语法：| 表头 | 表头 | + 分隔行 | --- | --- |，支持对齐方式：

  • :--- 左对齐

  • :---: 居中

  • ---: 右对齐

| 姓名 | 年龄 | 性别 |
| :--- | :--: | ---: |
| 小明 | 20   | 男   |
| 小红 | 18   | 女   |
| 小刚 | 22   | 男   |

5. 数学公式 (LaTeX)¶

Markdown 支持 LaTeX 语法，是撰写数学模型的利器。

核心规则¶

  • 行内公式（文字中插入）：用 $ 包裹，示例： \(x_j \ge 0\)

  • 独立公式（单独成行居中）：用 $$ 包裹，示例：

\[ \max Q = \sum_{j=1}^3 c_j x_j \]

线性规划专用符号表 (Modeling Kit)¶

A. 核心常用符号¶

含义 语法 渲染效果 备注
任意/所有 \forall \(\forall\) 线性规划约束常用
存在 \exists \(\exists\)
最大化 \max \(\max\) 目标函数专用
最小化 \min \(\min\) 目标函数专用
大于等于 \ge \(\ge\) 推荐使用（等价于 \geq）
小于等于 \le \(\le\) 推荐使用（等价于 \leq）

乘积 \prod \(\prod\)
非负约束 x \ge 0 \(x \ge 0\) 变量约束常用
属于 \in \(\in\) 如 \(x \in R\) （实数域）

B. 上下标详解¶

  • 下标：使用 _，单字符直接写 _i，多字符用花括号 _{ij}

    • \(x_j\) → x_j

    • \(p_{ij}\) → p_{ij}（❌ 错误写法：p_i_j）

  • 上标：使用 ^

    • \(x^2\) → x^2

    • \(e^{-x}\) → e^{-x}

  • 组合使用（求和/乘积常用）：

    • \(\sum_{j=1}^{n}\) → \sum_{j=1}^{n}

    • \(\prod_{i=1}^{m}\) → \prod_{i=1}^{m}

6. 避坑指南¶

  1. 空格是关键：

    • 标题 #、列表 -/1.、引用 > 后必须加空格

    • 代码块 ``` 后指定语言时，语言与反引号之间无空格

  2. 不要空格：

    • 加粗/斜体/删除线的符号与文字之间不能有空格（❌ 错误：** 内容 **）

  3. 符号格式：

    • 所有语法符号（#、*、()、[]、!、.）必须是英文半角符号

  4. 列表嵌套：

    • 子列表需在上一级基础上缩进 4 个空格或 1 个 Tab

  5. 公式语法：

    • 上下标多字符必须用花括号 {} 包裹（❌ 错误：x^10 会显示为 \(x^10\) ，正确：x^{10} → \(x^{10}\) ）
